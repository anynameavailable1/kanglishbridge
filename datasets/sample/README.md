# SYNTHETIC demonstration dataset

`synthetic_demo.csv` (20 rows) was written by an AI assistant for **smoke-testing the tooling only**.
- It has NOT been verified by a native Kannada speaker. Spellings, Kannada script and references may contain errors.
- It is far too small to train on and too small for meaningful BLEU/chrF numbers.
- **Never report scores from this file as real-world performance.**

Replace it with your own collected, human-verified data (see the root README, "Datasets").
